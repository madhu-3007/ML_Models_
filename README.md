Machine Learning - Supervised & Unsupervised Learning
📌 Project Overview
This repository contains my hands-on learning and implementation of various Machine Learning algorithms using Python.

The project is divided into two main sections:

🔵 Supervised Learning – Implemented using a Salary Dataset
🟢 Unsupervised Learning – Implemented using a House Dataset
The main objective of this repository is to understand how different Machine Learning algorithms work, including data preprocessing, model training, clustering, dimensionality reduction, and association rule mining.
